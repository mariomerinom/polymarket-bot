## What We Learned

- **`py-clob-client` v0.34.6 is a breaking change.** The `order_type` parameter was removed silently — no changelog entry caught before shipping. 13 live orders failed over 6+ hours (04:27–10:52 UTC) before the fix landed.
- **Stash-based multi-pipeline git is fragile.** Three parallel CI pipelines (5m, 15m, ETH) each auto-commit every cycle. The daily report workflow's stash pop lands in a dirty tree — the stash pop itself conflicts. The backup/reset/restore pattern is robust because it never tries to reconcile, just replaces.
- **Predictions store signal as string or dict depending on age.** Older predictions serialized the signal direction as a plain string; newer ones store a full dict. Any code that assumes a specific type on reasoning JSON needs an isinstance guard.
- **First day of live trading produced zero filled orders.** All 13 conviction≥3 bets fired but none executed. The SDK bug was the blocker, not market conditions or conviction thresholds.
