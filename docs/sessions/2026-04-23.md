## What We Learned

- **Polymarket crypto markets are "Up or Down" direction markets**, not "above $strike" markets. They resolve YES if close > open over the window. fair_p is intra-window conditional: at window open = 0.5, at close = step function. This changes the fair-p math entirely.
- **Post-merge hook has a post-rewrite gap**: `git pull --rebase` fires the post-rewrite hook instead of post-merge. The deploy restart wasn't triggering on CI rebases. Fixed via passing both hook types to the same check.
- **`$1` is not always a SHA in post-merge**: git passes "amend" as `$1` in some hook modes (post-rewrite). Guard added to ignore non-SHA inputs.
- **arb_loggers candle source bug**: original impl created a fake engine singleton that didn't have live data; fixed by passing the candle source through from the caller.
- **LLM as diagnostic, not decision**: arb_classifier and v4_diagnosis are read-only tools that name causes and hypothesize onset dates. Schema explicitly excludes buy/sell/direction/conviction outputs per no-agent-bias rule.
- **V4 decay is documented and named**: six independent indicators (EHR drift, regime WR collapse, shadow maker reversal, lab-production disconnect, FAK pilot, protection layer count) all point the same direction. The decision horizon is 2026-04-28.
