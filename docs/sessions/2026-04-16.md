## What We Learned

- **The memory leak is glibc, not Python.** tracemalloc confirmed Python heap stays at ~90MB while RSS grows to 650MB+ after 2h. The 560MB gap is glibc holding fragmented arenas from pandas/numpy buffers freed by pandas-ta. `MALLOC_ARENA_MAX=2` + `malloc_trim(0)` are the fix. Need 24h to confirm RSS stabilizes.
- **Signal EHR = +0.102 on BTC 5m (top 2% Akey scale).** The model genuinely identifies mispricings. The problem is execution: exec EHR = −0.028, a 13¢/dollar gap. Maker mode is the biggest lever — Akey et al. show moving from pure taker to maker reduces loss probability by 35.9pp.
- **Kalshi signal EHR = −0.241 (catastrophic).** Consistent with the long-running 0% WR on 340 7-day bets. The signal doesn't work on Kalshi — it's a separate decision pending.
- **7 perp pipelines were invisible in the daily report.** The consolidated report surfaces them for the first time. First look: eth_bybit, eth_hl, hl all at −0.10 signal EHR (7d, 90 bets each) — consistent with expected VWAP warm-up.
- **Datetime import shadowing is a silent killer.** An inner `from datetime import datetime, timezone` inside a conditional block shadowed the module-level import, causing `NameError: cannot access local variable 'datetime'` in 3 pipelines. Python's scoping rules make this non-obvious.
